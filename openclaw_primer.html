WebSocket connections must be authenticated using the existing JWT token passed as a query parameter on the upgrade request. The server validates the JWT synchronously before accepting the upgrade, and closes with code 4001 if the token is invalid or expired. Manager-role users see risk events; private documents are filtered to owners only.
